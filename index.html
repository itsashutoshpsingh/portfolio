2025 to now

Home SOC and detection lab

An end-to-end detection pipeline I built and run myself, from Windows telemetry to triaged alerts.

I write Sigma rules and Splunk correlation searches mapped to MITRE ATT&CK, and test each one against telemetry from the lab. Then I triage the alerts they raise and analyse the packet captures in Wireshark.

  • Elastic (ELK)
  • Splunk
  • Sysmon
  • Sigma
  • MITRE ATT&CK
  • Wireshark
  • Debian
Pipeline
  1. Windows endpointSysmon records process, network and file activity
  2. Elastic (ELK) on a hardened Debian hostCollects and indexes endpoint telemetry
  3. Sigma rules and Splunk correlation searchesEach one mapped to a MITRE ATT&CK technique
  4. Tested against lab telemetryEvery rule is checked against what the lab actually records
  5. Alert triageInvestigated with Wireshark packet captures
2026 · MSc dissertation

PrivDeFi: privacy-aware fraud detection for DeFi

Flags suspicious Ethereum and BNB Smart Chain transactions with federated graph neural network (GNN) anomaly detection.

Differential privacy keeps the shared model from leaking transaction data. I mapped the design against the EU's MiCA and DORA requirements, and studied rug pulls, flash-loan exploits and wash trading using on-chain data from Etherscan.

  • Python
  • Graph neural networks
  • Differential privacy
  • Etherscan
  • MiCA
  • DORA
Framework
  1. On-chain transactionsEthereum and BNB Smart Chain, via Etherscan
  2. Federated GNN clientsEach learns transaction-graph patterns locally
  3. Differential privacyLimits what the shared model reveals about any transaction
  4. Suspicious transactions flaggedInformed by research into rug pulls, flash-loan exploits and wash trading
2026 · MSc module

Machine learning intrusion detection

Trained and compared Random Forest and XGBoost on the CIC-IDS-2017 network traffic dataset. I chose XGBoost because it missed fewer real attacks (a lower false-negative rate).
