How I work

  1. 1

    Find it

    Scan, read the firmware, walk the attack path yourself. Nessus and Qualys first, then hands on hardware.

  2. 2

    Rank it

    CVSS gives the number. Context decides the order: what is exposed, what it protects, what the fix costs.

  3. 3

    Fix it with the engineers

    Down to the bootloader if that is where the flaw lives. Then automate the boring part so it stays fixed.

  4. 4

    Catch the rest

    Write the detection, map it to ATT&CK, test it until it fires on the attack and stays quiet otherwise.
