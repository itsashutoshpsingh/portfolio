# Ashutosh Pal Singh · Portfolio

Personal site for Ashutosh Pal Singh, security analyst (vulnerability management and threat detection; MSc Cyber Security Engineering, University of Warwick).

Live at **https://itsashutoshpsingh.github.io/portfolio/**

## Files

- `index.html`, `styles.css`, `app.js`: the site. No build step, no libraries.
- `404.html`: not-found page.
- `favicon.svg`, `og.png`: tab icon and link preview.
- `github/`: animated SVG cards and the README for the GitHub profile page.

## Design notes

Geist, with Geist Mono for data. Type sizes on a fixed scale, spacing on a fixed scale, flat dark surfaces, one film behind the hero and one behind the contact section. Motion is transform and opacity only, triggered by IntersectionObserver, so nothing runs on scroll. Reduced motion gets opacity only. Everything is visible without JavaScript.
